# Basketball Score Counter

This project is a web-based basketball scoreboard application built using HTML, CSS, and JavaScript. It features a luxury dark court aesthetic with gold accents, designed to overlay a basketball background image.

## Features
* **Dual Team Tracking:** Independently manages real-time scores for both Home and Guest teams.
* **Point Increments:** Features individual button controls to add +1, +2, or +3 points to either team.
* **Score Reset:** Includes a centered "New Match" button that clears both score arrays and updates the display back to zero.

## File Structure
* `index.html`: Contains the structural layout, team columns, and button elements.
* `index.css`: Sets up the flexbox layout, centers elements over the background image, and defines the gold and black theme.
* `index.js`: Handles the score calculations and modifies the text content of the display elements on click events.

## Setup Instructions
1. Save `index.html`, `index.css`, and `index.js` in the same directory.
2. Place the background image file named `istockphoto-499287000-612x612.jpg` into that same directory.
3. Open `index.html` in any standard web browser to view and run the application.
